## Быстрый старт

### Три шага для начала работы

1. **Установите браузерное расширение**
2. **Запустите мостовой сервис**
3. **Настройте инструменты MCP**

Всё очень просто!

---

## Руководство по установке

### Шаг 1: Установка браузерного расширения

#### Установка в Chrome / Edge

1. Скачайте файлы проекта
   ```bash
   git clone https://github.com/WongJingGitt/mcp_bridge.git
   ```

2. Откройте браузер, перейдите на страницу управления расширениями
   - Chrome: `chrome://extensions/`
   - Edge: `edge://extensions/`

3. Включите «Режим разработчика» (переключатель в правом верхнем углу)

4. Нажмите «Загрузить распакованное расширение»

5. Выберите корневой каталог проекта `mcp_bridge`

6. Убедитесь, что расширение включено (иконка отображается в цвете)

#### Проверка установки

Перейдите на [DeepSeek Chat](https://chat.deepseek.com) — в правом нижнем углу должно появиться плавающее окно MCP Bridge.

### Шаг 2: Установка мостового сервиса

Мостовой сервис — это промежуточный слой, связывающий браузер и инструменты MCP.

#### Способ первый: использование исполняемого файла (рекомендуется)

**Windows**
1. Скачайте `mcp-bridge-server-windows.exe` из [Releases](https://github.com/WongJingGitt/mcp_bridge_server/releases)
2. Запустите двойным щелчком
3. Появление сообщения «Server running on http://localhost:3849» означает успех

**macOS**
1. Скачайте `mcp-bridge-server-macos`
2. Дайте права на выполнение:
   ```bash
   chmod +x mcp-bridge-server-macos
   ```
3. Запустите:
   ```bash
   ./mcp-bridge-server-macos
   ```

**Linux**
1. Скачайте `mcp-bridge-server-linux`
2. Дайте права на выполнение и запустите:
   ```bash
   chmod +x mcp-bridge-server-linux
   ./mcp-bridge-server-linux
   ```

#### Способ второй: использование исходного кода Python

**Предварительное требование**: Python 3.8+

```bash
# 1. Клонирование репозитория
git clone https://github.com/WongJingGitt/mcp_bridge_server.git
cd mcp_bridge_server

# 2. Установка зависимостей
pip install -r requirements.txt

# 3. Запуск сервиса
python utils/mcp_bridge.py
```

#### Проверка сервиса

Откройте браузер, перейдите по адресу http://localhost:3849/health

Должно отобразиться:
```json
{
  "status": "healthy"
}
```

## Руководство по настройке

### Настройка сервисов инструментов MCP

#### Расположение файла конфигурации

MCP Bridge ищет файл конфигурации в следующих местах:

- **Windows**: `%APPDATA%\mcp-bridge\config\mcp-config.json`
- **macOS**: `~/Library/Application Support/mcp-bridge/config/mcp-config.json`
- **Linux**: `~/.config/mcp-bridge/config/mcp-config.json`

#### Быстрый доступ к файлу конфигурации

**Windows**
```powershell
# Открыть каталог конфигурации
explorer %APPDATA%\mcp-bridge\config
```

**macOS / Linux**
```bash
# Открыть каталог конфигурации
open ~/Library/Application\ Support/mcp-bridge/config  # macOS
xdg-open ~/.config/mcp-bridge/config  # Linux
```

#### Создание файла конфигурации

Если файл конфигурации отсутствует, создайте `mcp-config.json`:

```json
{
  "mcpServers": {
    "filesystem": {
      "enabled": true,
      "command": "npx",
      "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\"],
      "description": "Инструмент доступа к файловой системе"
    }
  }
}
```

#### Настройка через страницу параметров расширения

1. Откройте страницу управления расширениями (`chrome://extensions/`)
2. Найдите MCP Bridge, нажмите «Подробнее»
3. Нажмите «Параметры расширения»
4. Переключитесь на вкладку «Конфигурация сервисов»
5. Вставьте JSON-конфигурацию, нажмите «Сохранить»

### Подробное описание формата конфигурации

#### Полный формат конфигурации

```json
{
  "mcpServers": {
    "Имя сервиса": {
      "enabled": true,           // включён ли
      "command": "исполняемый файл",    // команда
      "args": ["параметр1", "параметр2"], // массив параметров
      "description": "Описание сервиса"  // описание
    }
  }
}
```

#### Поддерживаемые три формата

Расширение поддерживает три формата JSON, что упрощает копирование конфигурации из разных источников:

**Формат 1: полная конфигурация**
```json
{
  "mcpServers": {
    "service1": {
      "command": "npx",
      "args": ["-y", "package"]
    }
  }
}
```

**Формат 2: один сервис** (после вставки будет предложено ввести имя сервиса)
```json
{
  "command": "npx",
  "args": ["-y", "@modelcontextprotocol/server-filesystem", "D:\\"]
}
```

**Формат 3: несколько сервисов** (автоматическое распознавание)
```json
{
  "weather": {
    "command": "python",
    "args": ["weather_server.py"]
  },
  "database": {
    "command": "node",
    "args": ["db_server.js"]
  }
}
```

### Конфигурации часто используемых инструментов MCP

#### Инструмент файловой системы

**Функция**: чтение и запись локальных файлов

**Windows**
```json
{
  "filesystem": {
    "enabled": true,
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "C:\\"],
    "description": "Инструмент доступа к файловой системе"
  }
}
```

**macOS / Linux**
```json
{
  "filesystem": {
    "enabled": true,
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-filesystem", "/"],
    "description": "Инструмент доступа к файловой системе"
  }
}
```

#### Инструмент Git

**Функция**: управление Git-репозиториями

```json
{
  "git": {
    "enabled": true,
    "command": "uvx",
    "args": ["mcp-server-git", "--repository", "C:\\myrepo"],
    "description": "Инструмент управления Git-репозиторием"
  }
}
```

#### Инструмент SQLite

**Функция**: работа с базой данных SQLite

```json
{
  "sqlite": {
    "enabled": true,
    "command": "uvx",
    "args": ["mcp-server-sqlite", "--db-path", "C:\\data\\mydb.sqlite"],
    "description": "Доступ к базе данных SQLite"
  }
}
```

#### Инструмент PostgreSQL

**Функция**: работа с базой данных PostgreSQL

```json
{
  "postgres": {
    "enabled": true,
    "command": "npx",
    "args": ["-y", "@modelcontextprotocol/server-postgres", "postgresql://user:pass@localhost/mydb"],
    "description": "Доступ к базе данных PostgreSQL"
  }
}
```

## Учебное пособие

### Базовый процесс использования

#### 1. Откройте поддерживаемую ИИ-платформу

Перейдите на любую поддерживаемую платформу:
- [DeepSeek Chat](https://chat.deepseek.com)
- [Tongyi Qianwen](https://www.tongyi.com)
- [Tencent Yuanbao](https://yuanbao.tencent.com)
- [Doubao](https://www.doubao.com)

#### 2. Начните диалог

MCP Bridge автоматически внедрит список инструментов в System Prompt.

Состояние можно увидеть во всплывающем окне в правом нижнем углу.

#### 3. Попросите ИИ вызвать инструмент

**Пример диалога**:

```
Пользователь: Помоги мне вывести список всех инструментов сервиса filesystem

ИИ: Я помогу тебе получить список инструментов сервиса filesystem...
<tool_code>
{
  "tool_name": "list_tools_in_service",
  "arguments": {
    "service_name": "filesystem"
  }
}
</tool_code>

[Система автоматически выполняет инструмент и возвращает результат ИИ]

ИИ: Сервис filesystem предоставляет следующие инструменты:
1. read_file — чтение содержимого файла
2. write_file — запись в файл
3. list_directory — вывод содержимого каталога
...
```

#### 4. Просмотр состояния выполнения

Всплывающее окно в правом нижнем углу отображает в реальном времени:
- 🔄 Выполняется: инструмент работает
- ✅ Успех: выполнение инструмента завершено
- ❌ Ошибка: выполнение инструмента завершилось с ошибкой

### Дополнительные функции

#### Ручное обновление System Prompt

**Сценарии использования**: 
- Добавлены новые инструменты MCP
- Нужно обновить список инструментов в текущем диалоге

**Шаги**:
1. Нажмите значок **🔄** в заголовке плавающего окна в правом нижнем углу
2. Система заново получит список инструментов
3. System Prompt автоматически внедрится в поле ввода

#### Повторное обнаружение вызова инструмента

**Сценарии использования**:
- После обновления страницы вызов инструмента не сработал
- Ответ ИИ завершён, но инструмент не выполнен

**Шаги**:
1. Нажмите значок **⏰** в заголовке плавающего окна
2. Система повторно извлекает вызов инструмента из последнего сообщения
3. После обнаружения он выполняется автоматически

#### Ручной ввод вызова инструмента

**Сценарии использования**: все автоматические способы обнаружения не сработали

**Шаги**:
1. Скопируйте часть ответа ИИ, содержащую `<tool_code>`
2. Нажмите на плавающее окно, чтобы развернуть его
3. Вставьте текст в поле ввода
4. Нажмите «Отправить в MCP»

### Функции страницы настроек

Откройте страницу управления расширениями → MCP Bridge → Подробнее → Параметры расширения

#### Вкладка управления сайтами

**Автоматическая инъекция System Prompt**

- Описание функции: узнайте, как работает автоматическая инъекция
- Настройка сайтов: независимая настройка для каждой ИИ-платформы
- Настройка порта: изменение порта мостового сервиса (по умолчанию 3849)

#### Вкладка управления сервисами

**Просмотр и управление сервисами MCP**

- Включение/отключение: управление состоянием сервиса через переключатель
- Просмотр состояния: отображение состояния работы сервиса в реальном времени
  - ✅ Работает
  - ⏸️ Остановлен
  - ❌ Ошибка
- Перезапуск сервиса: нажмите кнопку «🔄 Перезапустить»
- Удаление сервиса: нажмите кнопку «🗑️ Удалить»

#### Вкладка конфигурации сервисов

**Добавление нового сервиса**

1. Вставьте JSON-конфигурацию (поддерживаются три формата)
2. Выберите, нужно ли «автоматически заменять существующие сервисы»
3. Нажмите «Сохранить конфигурацию»
4. Сервис будет перезагружен автоматически

## Частые вопросы

### Установка и настройка

#### В: Иконка расширения отображается серым?

**О**: Это означает, что расширение не загружено или отключено.

**Решение**:
1. Перейдите по адресу `chrome://extensions/`
2. Убедитесь, что MCP Bridge включён
3. Нажмите значок обновления для повторной загрузки

#### В: Не могу найти файл конфигурации?

**О**: При первом запуске файл конфигурации не существует, его нужно создать вручную.

**Решение**:
1. Создайте каталог конфигурации
2. Создайте файл `mcp-config.json`
3. Составьте конфигурацию в соответствии с [руководством по настройке](#руководство-по-настройке)

#### В: Как изменить порт мостового сервиса?

**О**: Измените его на странице настроек расширения.

**Шаги**:
1. Откройте настройки расширения → Управление сайтами
2. Измените «Порт мостового сервиса»
3. Нажмите «Сохранить»
4. Перезапустите мостовой сервис с новым портом

### Проблемы использования

#### В: System Prompt не внедряется?

**Возможные причины**:
1. Мостовой сервис не запущен
2. Не включена «автоматическая инъекция»
3. Это не новый диалог

**Решение**:
1. Проверьте работоспособность http://localhost:3849/health
2. Включите «автоматическую инъекцию» для соответствующего сайта на странице настроек
3. Попробуйте вручную обновить System Prompt (значок 🔄 в плавающем окне)

#### В: Вызов инструмента не срабатывает?

**Чек-лист**:
- [ ] Содержит ли ответ ИИ тег `<tool_code>`?
- [ ] Отображается ли в плавающем окне «Выполняется»?
- [ ] Есть ли в консоли браузера сообщения об ошибках?

**Решение**:
1. Попробуйте «Повторное обнаружение» (значок ⏰ в плавающем окне)
2. Используйте «Ручной ввод» как резервный вариант
3. Просмотрите логи в консоли браузера (F12)

#### В: Результат инструмента не отправляется автоматически?

**Возможная причина**: некорректная конфигурация поля ввода

**Решение**:
1. Откройте консоль браузера (F12)
2. Выполните: `document.querySelector('textarea')`
3. Если возвращается `null`, значит селектор не совпадает
4. Создайте Issue на GitHub, мы обновим конфигурацию

#### В: Сервис отображается как «Остановлен»?

**Возможные причины**:
1. Ошибка в конфигурации сервиса (неправильные command или args)
2. Не установлены необходимые зависимости

**Решение**:
1. Проверьте правильность конфигурации
2. Попробуйте выполнить команду вручную в терминале
   ```bash
   npx -y @modelcontextprotocol/server-filesystem C:\
   ```
3. Установите отсутствующие зависимости
4. Нажмите «Перезапустить сервис»

### Проблемы производительности

#### В: Страница загружается медленнее?

**О**: Возможно, время инъекции скрипта слишком раннее.

**Решение**: пока не требуется ручных действий, оптимизация инъекции скриптов в процессе.

#### В: Инструмент выполняется очень медленно?

**О**: Некоторые инструменты (например, работа с большими файлами) сами по себе требуют времени.

**Подсказка**: плавающее окно отображает состояние «Выполняется», пожалуйста, подождите.

## Устранение неполадок

### Процесс диагностики проблем

```
Сбой вызова инструмента
    ↓
Проверьте, работает ли мостовой сервис
    ↓ Да
Проверьте, включён ли сервис MCP
    ↓ Да
Проверьте, содержит ли ответ ИИ <tool_code>
    ↓ Да
Просмотрите состояние плавающего окна и сообщение об ошибке
    ↓
Решите проблему в соответствии с сообщением об ошибке
```

### Сбор диагностической информации

При возникновении проблем сбор следующей информации поможет в диагностике:

1. **Информация о браузере**
   - Тип и версия браузера
   - Версия расширения

2. **Состояние сервиса**
   - Перейдите по адресу http://localhost:3849/health
   - Сделайте скриншот журнала консоли сервиса

3. **Журналы расширения**
   - Откройте консоль браузера (F12)
   - Скопируйте все журналы, начинающиеся с `[MCP Bridge]`

4. **Файлы конфигурации**
   - Скопируйте содержимое `mcp-config.json`
   - Скопируйте конфигурацию соответствующей платформы из `api_list.json`

### Сброс расширения

Если расширение работает некорректно, попробуйте сбросить:

1. Перейдите по адресу `chrome://extensions/`
2. Удалите MCP Bridge
3. Загрузите расширение заново
4. Очистите кэш браузера (опционально)

### Сброс конфигурации

Удалите файл конфигурации и начните заново:

**Windows**
```powershell
Remove-Item -Recurse -Force $env:APPDATA\mcp-bridge
```

**macOS / Linux**
```bash
rm -rf ~/Library/Application\ Support/mcp-bridge  # macOS
rm -rf ~/.config/mcp-bridge  # Linux
```

| Действие | Горячая клавиша |
|----------|-----------------|
| Открыть управление расширениями | Введите в адресной строке `chrome://extensions/` |
| Открыть инструменты разработчика | `F12` или `Ctrl+Shift+I` |
| Обновить страницу | `F5` или `Ctrl+R` |
| Жёсткое обновление (очистка кэша) | `Ctrl+Shift+R` |
